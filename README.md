# Data Professional Survey Dashboard | Power BI

##  Project Overview

An interactive Power BI dashboard built to analyze survey responses from data professionals.

The dashboard provides insights into job roles, salaries, programming language preferences, work-life balance, salary satisfaction, and the perceived difficulty of entering the data field.3

##  Tools Used

- Power BI Desktop
- DAX
- Power Query
- Data Visualization

##  Key Metrics3

- Total Survey Takers: 630
- Average Age of Survey Takers: 29.87 years
                                                   
## Dashboard Analysis

The dashboard includes:

- Country of Survey Takers
- Average Salary by Job Title
- Favourite Programming Language
- Difficulty Breaking into Data
- Happiness with Work-Life Balance
- Happiness with Salary

##  Key Features

- Interactive data visualizations
- KPI cards
- Salary analysis by job role
- Programming language analysis
- Career difficulty analysis
- Work-life balance and salary satisfaction analysis
